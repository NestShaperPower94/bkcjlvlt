## 💡 Pro Tips

- **Use Combinator** — Combine synths + effects into performance patches (e.g., lead synth + delay + reverb)
- **Tab for Cables** — Press Tab to flip rack showing CV/audio cables for modular patching
- **Parallel Processing** — Use Spider Audio/CV splitters for parallel compression/effects chains
- **Blocks Workflow** — Create reusable music blocks (8-bar patterns) for song arrangement
- **Reason as Plugin** — Load Reason Rack as VST3 in Ableton/FL Studio for hybrid workflows

## 🛠 Troubleshooting

### High CPU usage

```powershell
# Bounce to audio
# Right-click track > Bounce Track to Audio (freezes synths)

# Reduce polyphony
# Synth > Polyphony = 8 voices (from 16-32)

# Disable unused effects
# Bypass effects in rack when not needed
```

### Rack extensions not loading

```powershell
# Update Reason
# Help > Check for Updates

# Re-download extensions
# Reason Studios Account > My Products > Re-download

# Check authorization
# Account > Authorize Computer (internet required)
```

### Audio interface not recognized

```powershell
# Check ASIO driver
# Preferences > Audio > Driver = ASIO (install ASIO4ALL if needed)

# Set buffer size
# Preferences > Audio > Buffer = 512 samples (reduce latency)

# Restart Reason
# Close completely, reopen to re-scan audio devices
```
